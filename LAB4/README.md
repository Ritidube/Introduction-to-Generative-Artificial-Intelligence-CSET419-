Text Generation using NLP

    This repository contains implementations of different text generation models developed as part of a Generative AI / NLP lab project. The project demonstrates how various language models generate text and how model complexity affects output quality.

Objective

    Understand text generation concepts
    Implement and compare multiple language models
    Analyze generated text quality

Models Implemented

    N-gram Language Model
    Recurrent Neural Network (RNN)
    Gated Recurrent Unit (GRU)
    Long Short-Term Memory (LSTM)
    Transformer (Self-Attention)

Dataset

    A small custom text corpus related to Artificial Intelligence and NLP is used for training all models. The same dataset is used to ensure fair comparison.

Key Observations

    N-gram reproduces seen patterns without context understanding
    RNN captures short-term dependencies
    GRU and LSTM generate more coherent text
    Transformer captures global context but needs larger data
